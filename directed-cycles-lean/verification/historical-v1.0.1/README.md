# Historical Lean 4.34 evidence

These files belong to the unchanged v1.0.1 release, not the Lean 4.35 Palomar port.
The original source archive and exact uncompressed evidence remain available in
[release v1.0.1](https://github.com/methuku-git-hub/Nearly-linear-directed-cycles-in-vertex-transitive-digraphs/releases/tag/v1.0.1).

`pre-palomar-v1.0.1-certificate.json` is the original `certificate.json`, renamed
to make its scope explicit. The graph was compressed without changing its contents:

```sh
gzip -dc main-constant-closure.json.gz > main-constant-closure.json
```

Hashes in the original certificate refer to the original uncompressed files
and layout. To reproduce that layout, extract the release archive. These
records make no claim about Palomar review or independent checker results.
